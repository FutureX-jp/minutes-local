# Teams会議ローカル議事録ツール

Teams（Zoom / Webex / Google Meet などにも対応）の会議を、
**画面録画 ＋ 音声の文字起こし ＋ 発話と画面の同期表示** で議事録にするツールです。

## いちばん大事なこと

**会議の内容は、外に一切出ません。**

録画も文字起こしも議事録づくりも、全部あなたのPCの中だけで終わります。
クラウドにアップロードしません。文字起こしのAIもPCの中で動きます。

（ネットに繋ぐのは「初回のモデルのダウンロード」と「更新の確認」だけです）

## ダウンロード

**[→ 最新版はこちら](../../releases/latest)**

`議事録ツール_vXX.zip` を落として、**「議事録ツール」フォルダごと**
デスクトップなどにコピーしてください。

> ⚠ **`議事録ツール.exe` だけを取り出しても動きません。**
> `_internal` フォルダが一緒に要ります。フォルダごとコピーしてください。

## 使い方

1. `議事録ツール.exe` をダブルクリック
2. 「見張りを始める」を押す（以降、会議が始まると**自動で録画**します）
3. 会議が終わると、議事録が自動で出来上がります

`議事録一覧.html` から、過去の議事録を**横断して検索**できます。

## できること

- **自動で録画**（会議が始まったのを検出して勝手に録る。押し忘れがない）
- **話者の区別**（自分／相手）
- **発話をクリックすると、そのときの画面が出る**
- **決定事項・宿題・課題**を自動で拾う
- **全部の議事録を横断して検索**／宿題ボード
- **Wordで書き出し**（人に渡すとき用）
- **用語集**を育てられる（業界の専門用語の誤変換が減っていきます）

## 動かすのに要るもの

| | |
|---|---|
| OS | Windows 10 / 11（64bit） |
| ディスク | 展開後に約 400MB ＋ 会議の録画ぶん |
| 初回のみ | 文字起こしモデルのダウンロード（約1.5GB・1回だけ） |

## うまく開かないときは

フォルダの中の **「うまく開かないとき.txt」** を見てください。

それでも分からないときは、
**`データ\起動エラー.txt`** が出来ているので、そのファイルを送ってください。
（このファイルに**会議の内容は入っていません**。エラーの内容だけです）

## 更新について

新しい版が出ると、アプリが自分で気づいてお知らせします。

- **録画中・文字起こし中は絶対に更新しません**（会議が飛ばないように）
- 更新に失敗したら**前の版に自動で戻ります**
- 中身が変わっていない部分は落とし直しません（**更新は約14MB**）
